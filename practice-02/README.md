# practice-02 — сортировки по ограничениям

Три задачи на выбор сортировки под ограничения входных данных: фиксированный диапазон, узкий диапазон и равномерное распределение.

## задачи из елёрна

### Вопрос 1

Номер вагона — целое число от 0 до 9999. Количество вагонов велико, а диапазон достаточно широк, чтобы хранить частоту каждого номера было неудобно.

Задание: выберите подходящий метод сортировки по ограничениям задачи и реализуйте его для описанных данных. Проверьте корректность и укажите сложность алгоритма.

Примеры тестовых данных:

Вход: [9999, 12, 100, 12]; ожидаемый результат: [12, 12, 100, 9999].
Вход: [7, 70, 700]; ожидаемый результат: [7, 70, 700].

### Вопрос 2

Дан большой список результатов броска кубика: целые числа от 1 до 6. Нужно вывести результаты по возрастанию и посчитать повторы.

Задание: выберите подходящий метод сортировки по ограничениям задачи и реализуйте его для описанных данных. Проверьте корректность и укажите сложность алгоритма.

Примеры тестовых данных:

Вход: [6, 1, 6, 3, 2]; ожидаемый результат: [1, 2, 3, 6, 6].
Вход: [4, 4, 2, 5]; ожидаемый результат: [2, 4, 4, 5].

### Вопрос 3

Нормированное расстояние

Датчик выдаёт числа double из интервала [0, 1). Значения примерно равномерно распределены. Нужно отсортировать большой массив, сначала распределив значения по интервалам.

Задание: выберите подходящий метод сортировки по ограничениям задачи и реализуйте его для описанных данных. Проверьте корректность и укажите сложность алгоритма.

Примеры тестовых данных:

Вход: [0.42, 0.11, 0.87, 0.35]; ожидаемый результат: [0.11, 0.35, 0.42, 0.87].
Вход: [0.01, 0.99, 0.50]; ожидаемый результат: [0.01, 0.50, 0.99].


## Итог

| Вопрос | Алгоритм | Время | Дополнительная память |
|---|---|---|---|
| 1. Номера вагонов 0..9999 | LSD radix sort, base 10 | O(4 · (n + 10)) = O(n) | O(n + 10) |
| 2. Результаты кубика 1..6 | counting sort | O(n + 6) = O(n) | O(6) = O(1) |
| 3. Нормированные расстояния [0, 1) | bucket sort, b = max(1, n / 8) | expected O(n), worst O(n log n) | O(n) |

## Тесты

123 теста: примеры из задания, пустые и одиночные массивы, дубликаты, границы диапазонов, невалидные значения и случайные массивы до 100 000 элементов со сверкой с `Arrays.sort`.

Из корня репозитория:

```bash
mvn -pl practice-02 test
```

## Использование ИИ

В работе использовался ИИ, но не для списывания алгоритмов. Алгоритмы писались мной с последующей проверкой и замечаниями от ИИ. ИИ применялся для создания тестов, шаблонного кода и ревью моего кода.
